# 変更説明書: アーキテクチャ資料（PowerPoint & インフォグラフィックHTML）

## 1. 概要
本プロジェクト（毎朝自動更新AIニュースまとめシステム）の技術構成・仕組み・完全無料運用の根拠を体系化し、備忘録および他者へのプレゼンテーションに活用できる2種類の高品質資料を作成しました。

## 2. 成果物の詳細

### ① PowerPointスライド (ai_news_system_architecture.pptx)
- 格納場所: プロジェクトルート直下 / ai_news_system_architecture.pptx
- デザイン: 青（濃紺 #0F233C、ロイヤルブルー #1A528A、スレートグレー）を基調とした落ち着いたフォーマルな16:9ワイドスライド
- スライド構成（全8枚）:
  1. 表紙: システム名・サブタイトル・概要
  2. 背景と目的: 直面していた課題（激流のAI動向、英語の壁、アプリの煩雑さ）と解決策
  3. 全体アーキテクチャ: 4層構成（収集・自動化・AI要約・配信）
  4. 採用技術スタックと選定理由: GitHub Actions, Google Gemini API, GitHub Pages, Python/Jinja2
  5. 完全無料運用のメカニズム: 月2,000分枠の0.9%消費、Gemini Free Tierの1日1回一括コール最適化、Pages静的配信
  6. 自動処理パイプライン詳細: 毎朝JST 6:30の5ステップ処理フロー
  7. 拡張性と今後の展望: 情報源追加、マルチ配信（LINE/Discord）、アーカイブ機能
  8. まとめ: サーバーレス個人DXの実現価値

### ② HTML形式インフォグラフィック (docs/infographic.html)
- 格納場所: docs/infographic.html （GitHub Pagesでもそのまま公開・閲覧可能）
- 公開URL: https://cluclu-land.github.io/ai-news-digest/infographic.html
- デザインと動き:
  - 洗練されたモダンダークテーマとサイバーパンク風のネオングロー効果
  - SVGアニメーションによるデータフロー可視化（破線パス上を流れる光線パルス）
  - 主要KPIカード（0円運用、35秒処理、0.9%消費率、100%メンテフリー）
  - 各コンポーネント（Actions, Gemini, Pages, Python）のインタラクティブカード
  - スマホ・PC双方で崩れず閲覧できる完全レスポンシブ設計
- 連携機能:
  - AIニュースまとめ本編（index.html）のフッターにインフォグラフィックへの導線を追加
  - インフォグラフィック上部に本編へ戻るナビゲーションバーを配置

## 3. 生成・管理スクリプト
- scripts/generate_pptx.py: python-pptxライブラリを利用し、テキストや色、シェイプ位置をミリ単位で調整してプロ仕様のスライドを自動生成するスクリプト。
