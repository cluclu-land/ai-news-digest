完全無料（Zero-Cost）の成立ロジック

  • GitHub Actionsの無料枠: 1回あたり約35秒の実行。月30日動かしても約18分しか消費せず、月間2,000分の無料枠の1%未満です。
  • Gemini APIのFree Tier: 記事を1本ずつではなく全件一括でプロンプトに投げる設計のため、API消費は1日わずか1回。無料上限（1,500回/日）を大幅に下回ります。
  • GitHub Pagesの静的ホスティング: サーバーを常時起動する必要がなく、生成されたHTMLファイルを静的に配信するためサーバー費用は永久に0円です。
📱

ブラウザ閲覧（PWA風）を選んだ理由

  • OSに依存しない: iPhone (iOS) でも Android でも、パソコンでも、URLさえ知っていれば全く同じUIで閲覧できます。
  • ストア審査・メンテ不要: アプリストアの公開審査やOSアップデートによるアプリ破損のメンテナンスコストがゼロになります。
  • ワンタップ起動: ブラウザの「ホーム画面に追加」を行うだけで、ネイティブアプリ同様のアプリアイコンから即起動できます。
